# Page Replacement Simulator (Week 5)

FIFO, LRU and Optimal page replacement, written only in C. The processes talk through
POSIX message queues, and the website is generated by C code.

## How it works
1. The browser opens the C web server (`server`) and submits the form.
2. The server runs `mqclient`, which sends a request to the **core** process on the `/pr_req` queue.
3. **core** runs the algorithms, builds the HTML page with `page.c`, and sends it back on the
   client's reply queue (in chunks).
4. **core** also sends a log line to the **logger** process, which writes `simulation.log`.

## Run (Linux only; use Docker on Mac)
    docker build -t pr-sim .
    docker run --rm -p 8000:8000 pr-sim
Then open http://localhost:8000. On Linux or Codespaces you can run `./run.sh` instead.

## Test the algorithms
    make test

Sample check: `7 0 1 2 0 3 0 4 2 3`, 3 frames gives FIFO 9 faults, LRU 8, Optimal 6.
